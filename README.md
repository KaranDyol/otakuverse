# 🌌 OtakuVerse — Anime & K-Drama Hub

A modern, responsive web application for discovering, tracking, and exploring trending **Anime** and **Korean Dramas**.

Powered by:
- 🌸 **The Movie Database (TMDB) API** for Korean Dramas, ratings, posters & trailers.
- 🎌 **AniList GraphQL API** for trending Anime, episode guides & seasonal charts.
- ⚡ **Tailwind CSS & Phosphor Icons** for a dark-mode streaming UI.

---

## 🚀 How to Run Locally

You don't need to install anything! Simply:
1. Open this folder: `D:\Downloads\otakuverse`
2. **Double-click `index.html`** to open it directly in your browser (Chrome, Edge, Firefox, Brave).
3. That's it! The trending shows, search, and trailers will load instantly.

## 🌐 How to Host It Online for FREE (Your Own Link)

You can host this for free in 60 seconds with **Vercel** or **GitHub Pages**:

### Option 1: Drag & Drop via Netlify Drop (Easiest - No command line!)
1. Go to **[app.netlify.com/drop](https://app.netlify.com/drop)**.
2. Drag and drop the `otakuverse` folder right onto the page.
3. You will immediately get a free live URL (e.g. `https://otakuverse.netlify.app`).

### Option 2: Deploy with Vercel & GitHub
1. Create a free repository on [GitHub.com](https://github.com/) named `otakuverse`.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Sign in to [Vercel.com](https://vercel.com/) with GitHub.
4. Click **"Add New Project"** and select `otakuverse`.
5. Click **"Deploy"** — you will get your free `otakuverse.vercel.app` domain!

## ✨ Features Included
- 🔥 **Dual-Feed Discovery:** Alternates top trending Anime and popular K-Dramas.
- 🔍 **Live Search:** Fast debounced search across both AniList and TMDB databases.
- 🏷️ **Genre Filtering:** Filter by Action, Romance, Fantasy, Comedy, Drama, Mystery.
- 🎬 **Trailer Player:** Watch official YouTube trailers inside a modal.
- 📌 **Persistent Watchlist:** Save your favorite shows to your browser's local storage with a click.
- 📱 **Fully Responsive:** Looks great on desktop, tablet, and mobile devices.
